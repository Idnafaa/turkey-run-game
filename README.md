PARDON RUN — The Great Turkey Escape is a side-scrolling runner where a turkey flees the Thanksgiving farmer across a farmyard at dusk, leaping hot ovens, ducking carving knives and snatching corn. Every hit lets the farmer close in, so reach the Pardon Gate at 1,200 m before he catches you — or end up on a platter.

## Run it

```sh
node serve.ts
```
lalu buka http://localhost:8080 — atau sajikan folder game/ dengan server statis apa pun.
