PARDON RUN — The Great Turkey Escape is a side-scrolling runner where a turkey flees the Thanksgiving farmer across a farmyard at dusk, leaping hot ovens, ducking carving knives and snatching corn. Every hit lets the farmer close in, so reach the Pardon Gate at 1,200 m before he catches you — or end up on a platter.

## Difficulty modes

Pick a mode on the title screen — click EASY / MEDIUM / HARD, press 1 / 2 / 3, or use ← / →. The turkey runs at exactly the same pace in every mode; modes differ only in lives, farmer behaviour and obstacle density. EASY gives 5 lives, a kinder farmer (bigger starting gap, gentler hits, faster gap recovery) and obstacles spaced far apart. MEDIUM is the classic v1 chase: 3 lives and the original spacing. HARD gives only 2 lives, the farmer starts closer, hits cost more gap, the gap recovers more slowly, and obstacles are packed tight. The chosen mode is shown in the HUD during the run and is kept when you restart; every mode still finishes at the same Pardon Gate at 1,200 m.

Controls: Space / W / ↑ / click — jump; S / ↓ — duck; 1 / 2 / 3 or ← / → on the title screen — choose difficulty.

## Run it

```sh
node serve.ts
```
lalu buka http://localhost:8080 — atau sajikan folder game/ dengan server statis apa pun.
